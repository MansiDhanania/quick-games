# Quick Games 🎲
Type an idea ("a raccoon stealing snacks from a supermarket"), get a playable single-file HTML canvas game generated by an LLM.

## Run
```bash
cp .env.example .env   # add a free key from https://console.groq.com/keys
node server.js         # Node 18+, no npm install needed
# open http://localhost:3000
```

## How it works
- `server.js` (zero deps) calls any OpenAI-compatible chat API (Groq by default) and returns one HTML document. The API key stays on the server.
- The browser runs the game in `<iframe sandbox="allow-scripts">` (no same-origin, no network, no popups, no forms) plus an injected CSP (`connect-src 'none'`).
- If the game throws a runtime error, a "fix it" button sends the code and error back to the model.
- Swap models/providers in `.env` (Groq, Gemini free tier, OpenRouter, local Ollama). Bigger models = better games; try `openai/gpt-oss-120b` on Groq for complex ones like golf.
